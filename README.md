# e-Gov Document Viewer（公文書ビューワー）

e-Gov 電子申請で届いた公文書（ZIP）をブラウザで表示するビューワーです。

- 公開URL: https://hanaoka-apps.github.io/egov-document-viewer/
- ZIP（二重ZIPも可）をドロップすると、通知書を様式どおりに表示します。
- 項目一覧・一覧表・CSV出力、添付ファイルの改ざんチェック、印刷時の縦横自動判定に対応しています。

## データの扱い

読み込んだファイルは、開いているブラウザの中だけで処理されます。
外部への送信は一切ありません（ページ内に通信処理はありません）。
このリポジトリには公文書を置かないでください（`.gitignore` で ZIP・XML・PDF・CSV を除外しています）。
